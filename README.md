# 서울 데이터 아틀라스

## 로컬 실행

Python 3이 설치된 환경에서 이 폴더로 이동하고 `python server.py`를 실행합니다.
브라우저에서 http://localhost:8080 에 접속합니다. 종료는 터미널에서 Ctrl+C입니다.

## 카카오 배경 지도

1. https://developers.kakao.com 에서 앱을 만들고 카카오맵 API 사용을 설정합니다.
2. JavaScript 키의 SDK 도메인에 `http://localhost:8080`을 등록합니다.
3. 화면의 **카카오 지도 연결**을 펼쳐 JavaScript 키를 입력합니다.

키가 없으면 로컬 GeoJSON으로 행정구역 미리보기가 표시됩니다. 카카오 배경에는 인터넷 연결과 유효한 키가 필요합니다. JavaScript 키는 브라우저에서 사용되는 공개 클라이언트 키이며 Admin 키나 REST API 키를 넣지 마세요. 입력 키는 해당 브라우저 localStorage에 저장됩니다.

## CSV 추가

UTF-8 (BOM 허용) CSV를 data 폴더에 저장한 뒤 **데이터 목록 새로고침**을 누릅니다. 같은 이름의 `.legend.json` 파일을 함께 두면 설명과 범례가 적용됩니다. 범례 파일이 없으면 수치의 최솟값~최댓값을 5단계로 자동 분류합니다.

```csv
자치구,진학률,취업률
종로구,78.5,66.2
중구,81.2,70.1
```

자치구 이름은 GeoJSON의 `properties.name`과 일치해야 합니다. `서울특별시 종로구` 대신 `종로구`를 사용합니다. 숫자 열은 자동으로 지표 목록에 나타납니다. 비어 있거나 숫자가 아닌 값, CSV에 없는 지역은 회색으로 표시합니다. 0은 유효한 수치입니다. 중복 자치구는 오류로 처리하고 매칭되지 않은 이름은 화면 아래에 표시합니다. 쉼표 포함 숫자는 CSV 따옴표로 감싸 주세요. CP949 CSV는 UTF-8로 다시 저장해야 합니다.

`my-data.csv`에 대응하는 `my-data.legend.json` 예시:

```json
{
  "title": "서울 진학·취업 현황",
  "description": "2025년 조사 / 출처와 지표 정의를 입력하세요",
  "sample": false,
  "source": "사용자 제공 통계",
  "regionColumn": "자치구",
  "unit": "%",
  "metrics": {
    "진학률": {"breaks": [60, 70, 80, 90]},
    "취업률": {"breaks": [50, 60, 70, 80]}
  }
}
```

breaks는 오름차순 구간 경계입니다. 경계 값 이상은 다음 색상 구간에 들어갑니다. `colors`를 지정할 경우 `#RRGGBB` 형식이며 개수는 breaks보다 하나 많아야 합니다. 지표별 unit과 colors도 지정할 수 있습니다. 화면의 평균은 수치가 있는 자치구의 단순 평균으로, 인구 등을 반영한 서울 전체 통계와 다를 수 있습니다.

## 범위와 검증

현재는 자치구 단위입니다. 행정동으로 변경하려면 GeoJSON과 CSV의 지역 키를 함께 변경해야 합니다. 기본 경계는 2013년 자료이므로 최신 경계가 필요한 분석에는 교체가 필요합니다. 샘플 CSV는 전부 가상 수치입니다.

서버는 127.0.0.1에만 바인딩합니다. 이 폴더는 정적 파일로 제공되므로 민감한 파일이나 개인 정보는 넣지 마세요.
